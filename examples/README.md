# Learning Examples and Tutorials

## 🎯 Hands-on Learning Examples

This directory contains practical examples and tutorials for learning AI/ML development, deployment, and evaluation.

## 📁 Example Categories

### 1. ML Pipeline Examples (`/ml-pipeline/`)
- **Basic Training**: Simple model training with scikit-learn
- **Advanced Training**: Complex pipelines with hyperparameter tuning
- **Feature Engineering**: Data preprocessing and feature creation
- **Model Comparison**: Comparing multiple algorithms

### 2. AI Agent Examples (`/ai-agents/`)
- **Basic Agent**: Simple conversational agent
- **Tool Integration**: Agent with custom tools
- **Multi-turn Conversations**: Context management
- **Agent Evaluation**: Performance assessment

### 3. API Development Examples (`/api-examples/`)
- **Basic API**: Simple ML prediction endpoint
- **Authentication**: Secured endpoints
- **Batch Processing**: Handling multiple predictions
- **Real-time Processing**: WebSocket integration

### 4. Deployment Examples (`/deployment/`)
- **Docker Setup**: Containerized applications
- **CI/CD Pipelines**: Automated deployment
- **Monitoring**: Logging and metrics
- **Scaling**: Load balancing and optimization

### 5. Evaluation Examples (`/evaluation/`)
- **Azure ADK**: Using Azure AI Evaluation SDK
- **Custom Evaluators**: Building domain-specific evaluators
- **Performance Metrics**: Comprehensive evaluation
- **Benchmarking**: Model comparison

## 🚀 Getting Started

1. **Choose your learning level:**
   - 🟢 Beginner: Start with `/beginner/` examples
   - 🟡 Intermediate: Move to `/intermediate/` examples  
   - 🔴 Advanced: Try `/advanced/` examples

2. **Follow the tutorial structure:**
   - Each example has a `README.md` with objectives
   - Step-by-step instructions in `tutorial.md`
   - Complete code in the example directory
   - Practice exercises in `exercises.md`

3. **Run the examples:**
   ```bash
   cd examples/[category]/[example-name]
   python run_example.py
   ```

## 📚 Tutorial Structure

Each tutorial follows this consistent structure:

```
example-name/
├── README.md           # Learning objectives and overview
├── tutorial.md         # Step-by-step instructions
├── requirements.txt    # Example-specific dependencies
├── data/              # Sample datasets
├── src/               # Example source code
├── tests/             # Unit tests
├── exercises.md       # Practice problems
└── solutions/         # Exercise solutions
```
