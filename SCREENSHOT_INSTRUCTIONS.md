## 📐 Screenshot Guidelines

### Technical Settings:
- **Resolution**: Full browser window
- **Format**: PNG for best quality
- **Zoom**: 100% browser zoom
- **Theme**: Default light theme

### Composition Tips:
- **Full Page**: Capture entire visible content
- **Focus Areas**: Highlight key interactive elements
- **Clean State**: No loading spinners or error messages
- **Readable Text**: Ensure all text is clearly visible

### Annotation Ideas:
- **Arrows**: Point to important buttons
- **Boxes**: Highlight key sections
- **Numbers**: Step-by-step workflows
- **Labels**: Explain technical terms
